# AeroPulse — 90-second demo

**0–15s — Orient.** “AeroPulse turns eight static airport datasets into a live operations system. This clock is replaying the source timestamps; every count you see is derived locally.” Switch from 5× to 30×.

**15–35s — Detect.** Point to the gate digital twin and the event feed. “As events are revealed, gate risk changes and exceptions enter the reasoned alert queue. Color is never the only signal.”

**35–60s — Investigate.** Open the highest-delay alert. “This is not a raw table. The investigation tells a causal story, then exposes connected passengers, baggage, gate events, maintenance, and retail activity through one relational graph.”

**60–75s — Navigate.** Close the panel, press Ctrl+K, search for the same flight or a gate, and reopen it. “Operators can move directly from a code, gate, airline, or destination to its full operational record.”

**75–90s — Prove.** Enable Lineage mode. “Judge Mode names the exact datasets behind each conclusion. The project has no backend, external database, or live API, and Reset returns the demo to a deterministic start in one click.”
